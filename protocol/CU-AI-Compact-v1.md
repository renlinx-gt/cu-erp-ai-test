# CU-AI Compact v1

Formato opcional de informes técnicos. Prefijo: `@CU-AI/1 RPT`.

| Clave | Significado |
|---|---|
| AG | Agente responsable |
| CMT | Commit |
| BR | Rama |
| HST | Equipo (no publicar IP privada) |
| PKG | Paquete / versión técnica |
| DISP | Versión visible |
| SEC | Invariantes de seguridad |
| RC | Causa raíz |
| CHG | Cambios realizados |
| TST | Pruebas y resultados |
| VERIF | Verificación observada |
| DKR | Docker |
| ENV | Entornos |
| SITE | Sitios |
| NEXT | Próximo paso |

Convenciones: `->` indica flujo, `=>` consecuencia. Evitar abreviaturas ambiguas; copiar literalmente errores y advertencias críticos. No afirmar PASS sin evidencia. Este formato no sustituye informes completos.
